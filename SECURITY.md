# Security Policy

## Supported version

Only the current `0.2.0-rc.3` source preview is reviewed. It is not a stable release and requires the exact source commits in `release-contract.json`.

## Report a vulnerability

Use this repository's **Security → Report a vulnerability** flow to submit a private report. Include the affected commit, configuration prerequisites, reproduction steps, impact, and suggested remediation when available.

Do not disclose credentials, private Session content, proprietary repositories, or unresolved exploit details in a public issue.

## Response expectations

The maintainer will acknowledge a valid private report, reproduce it against the supported source revision, and coordinate disclosure after a fix is available. No bounty program or guaranteed response-time SLA is offered.
